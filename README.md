# Програмний проєкт 3, варіант 10

Багатопотокове виконання обчислення за схемою №10. Параметри: nt = 4, a = 7, b = 9, c = 4, d = 8, g = 7, h = 9, i = 8, j = 5, k = 4, n = 3 (усього 64 дії, мінімальний час 16 одиниць).

## Структура проєкту

| Файл | Призначення |
|---|---|
| `program.cpp` | функція `main`: початок і завершення обчислення, вимірювання часу |
| `calculator.h`, `calculator.cpp` | клас `Calculator`: запускає 4 потоки, виконує дії (`f`) |
| `schedule.h`, `schedule.cpp` | клас `Schedule`: жорстко заданий розклад дій по потоках |
| `dependencies.h`, `dependencies.cpp` | клас `Dependencies`: засувки (`latch`) для залежностей між наборами |
| `action.h` | структура `Action`: набір і номер дії |
| `CMakeLists.txt` | опис збирання |
| `results.txt` | вихід програми |
| `diagram.png` | діаграма розподілу дій по потоках і точок синхронізації |

## Вимоги

- Компілятор з підтримкою C++20 (`<latch>`, `<syncstream>`): g++ 11 або новіший, MSVC 2019 (16.10) або новіший.
- CMake 3.10 або новіший (для збирання через CMake).

## Збирання

### Через CMake (CLion)

1. Відкрити папку проєкту в CLion (File → Open), вибрати саме папку.
2. Правою кнопкою на `CMakeLists.txt` → Load CMake Project.
3. Вибрати конфігурацію `lab3` і виконати Build → Build Project (`Ctrl+F9`).

### Через CMake в терміналі

```
cmake -S . -B build
cmake --build build
```

### Без CMake (g++)

```
g++ -std=c++20 -O2 program.cpp calculator.cpp dependencies.cpp schedule.cpp -o lab3
```

## Запуск

Windows:

```
lab3.exe
```

Linux:

```
./lab3
```

Якщо збирали через CMake, виконуваний файл лежить у папці збирання (`cmake-build-debug` у CLion або `build`).

Програма працює приблизно 16 секунд. Вона виводить `Обчислення розпочато.`, потім 64 повідомлення виду `З набору a виконано дію 3.` і наприкінці `Обчислення завершено. Тривалість обчислення ... секунд.`

### Вивід у файл

Через `cmd`:

```
lab3.exe > results.txt
```

У PowerShell оператор `>` записує файл у UTF-16, тому для файлу з виходом використовувати `cmd`.

### Кирилиця в консолі

Програма сама встановлює UTF-8 для консолі Windows. Якщо у вікні Run в CLion замість тексту «кракозябри», у налаштуваннях потрібно вказати UTF-8: Settings → Editor → General → Console → Default Encoding.

## Як працює програма

- `main` створює об'єкт `Calculator` і викликає `run()`. Дій у `main` не виконується.
- `Calculator::run()` запускає рівно 4 потоки `jthread` і чекає їх завершення.
- Кожен потік по черзі виконує свій стовпчик таблиці `Schedule`, 16 кроків. У кожному кроці всі 4 потоки зайняті.
- Перед дією потік викликає `Dependencies::wait_for()`, яка чекає на засувки наборів, від яких залежить дія. Після дії викликається `Dependencies::done()`, що зменшує лічильник засувки відповідного набору.
- Усі повідомлення виводяться через `osyncstream`.
